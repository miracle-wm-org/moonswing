One Flutter process draws the whole session: panels, wallpaper and desktop icons, overlays,
popups, an on-screen display and a lock screen. It is also the notification daemon, tray host,
screen-sharing and input-capture portal, polkit agent and screen locker.

Runs on any compositor with `wlr-layer-shell`; works best on
[miracle-wm](https://github.com/miracle-wm-org/miracle-wm).

:::caution
Unstable, and the config format can change at any time.
:::

Everything runs locally; there is no server. Linked Google, GitHub or GitLab accounts are
talked to directly from your machine — see the [privacy policy](privacy/).
